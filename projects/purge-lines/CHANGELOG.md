# Changelog

## 1.0.0 — 2026-10-13

Initial experimental community builder derived from the operator's public prime-lines macro. Explicit purge rectangle and tool adapters replace native-travel-bound sizing and implicit heater routing. Numeric tool slots, reserved wipe clearance, scaled extrusion and firmware checks reject invalid layouts and requests. No SAVE/RESTORE spans tool selection; the exit E/retract contract is explicit. Original-macro photos are attributed separately from software validation.
