Toolkit version:

Lệnh CLI đã dùng (ẩn địa chỉ/API key):
Profile đã ẩn thông tin và SHA256:
Tool / nozzle / vật liệu / nhiệt độ:
Lỗi nguyên văn / dòng G-code:
Hành vi kỳ vọng / hành vi thực tế:

Không gửi API key, full config có bí mật hoặc `.evidence.local.json` chưa rà dữ liệu riêng. Khi có lỗi chuyển động, dừng thử trên máy và tái hiện bằng profile/test phần mềm trước khi sửa.
